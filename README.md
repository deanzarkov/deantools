# DeanTools for Blender

DeanTools is a simple Blender add-on that serves as a hub for other DeanTools add-ons.
Find out more about the add-ons at [https://www.deantools.dev/](https://www.deantools.dev/)

## Installation

### Remote Repository (Recommended)
1. Open Blender Preferences (Edit > Preferences)
2. Go to "Get Extensions" tab
3. Navigate to the "Repositories" dropdown (top right) and click on the "Add Extension Repository" ("+" button) > "Add Remote Repository"
4. Add remote repository: `https://deanzarkov.github.io/deantools/index.json` (Optional: enable "Check for Updates on Startup")
5. Click "Create"
6. You can now search for "DeanTools" in the "Search Extensions" field and install the add-on


### Manual Installation
1. Download `deantools_v1_0_0.zip` from the latest release
2. In Blender, go to `Edit > Preferences > Get Extensions`
3. Click **"Install from Disk"**
4. Select the downloaded ZIP file

## Usage

DeanTools gathers any compatible add-ons and displays them in a single UI.
To switch between them, use the "Tool" drop-down field on top, to select the available add-on to show.
You can get more info about the specific tool from the "Options" menu, next to the "Tool" drop-down

## Compatibility

- Blender 5.0 and above
- Windows/Mac/Linux
